# 🎮 MVP Gaming

Мобильное приложение для бронирования **компьютерных и консольных клубов**
(ПК, PlayStation 5, Xbox) — Ташкент, Узбекистан.

Дизайн полностью соответствует прикреплённым макетам: тёмная тема, красный
акцент, нижняя навигация. Приложение работает на трёх языках — **Русский,
Oʻzbekcha, English** — и состоит из двух частей:

| Часть | Технологии | Назначение |
|------|------------|-----------|
| **Frontend** | Чистый HTML / CSS / JavaScript (без сборки) | Само приложение (клиент + админ) |
| **Backend**  | Node.js (без зависимостей) | Telegram-бот + API для кодов подтверждения |

---

## ✨ Возможности

### Для пользователя
- 🏠 **Главная** — промо-баннер, акции/промокоды, популярные клубы и клубы рядом.
- 🔎 **Поиск** клубов и игр.
- 🕹 **Карточка клуба** — галерея, рейтинг, характеристики ПК, список комнат, отзывы.
- 💻 **Комнаты** (Standard / VIP / Bootcamp / Premium / PlayStation 5) — полные
  характеристики (CPU, GPU, ОЗУ, монитор, периферия), доступные игры, фото/видео.
- 📅 **Бронирование** — выбор комнаты, даты, времени начала и длительности,
  применение промокода, расчёт стоимости со скидкой, подтверждение и «оплата».
- 🗺 **Карта** — стилизованная карта Ташкента с 2–3 клубами и списком.
- ❤️ **Избранное** — клубы, которые хочется посетить.
- 👤 **Профиль** — регистрация/вход по номеру телефона + **код в Telegram**,
  уровень MVP GOLD, баллы, история бронирований, скидки, поддержка, язык.
- 🎁 **Реферальная программа** — «Поделись приложением и получи скидку 20%».
- 💬 **Поддержка** — чат + FAQ.

### Для администратора клуба
Нижняя навигация заменяет «Избранное» на вкладку **Админ** (шестерёнка):
- 📊 **Панель администратора** — аналитика: уникальные посетители, просмотры
  карточки (+тренд), среднее время в игре, конверсия, график посещаемости,
  интерес по комнатам, всего бронирований; статус **В сети / Не в сети** и
  «Скрыть клуб».
- ✏️ **Редактирование клуба** — название, адрес, телефон, часы, описание,
  главное фото, фотогалерея, управление комнатами, «Добавить новую комнату».
- 🛠 **Редактирование комнаты** — вкладки «Характеристики ПК», «Услуги и игры»,
  «Фото и видео»: CPU/GPU/ОЗУ/монитор/периферия, цена, тип, места, игры, медиа.
- 🌟 **Управление отзывами** — ответы на отзывы, чат поддержки, FAQ,
  «Уведомить об акциях» (рассылка пользователям).

### Регистрация ПК-клуба
На экране профиля (для гостя) — кнопка **«Зарегистрировать клуб»**: заявка с
названием, геолокацией/адресом, контактным номером и ролью заявителя
(владелец / администратор / менеджер). Заявка уходит на backend (и, при
настройке `ADMIN_CHAT_ID`, в Telegram администратору платформы).

## 🚀 Быстрый старт

### Вариант 1. Только приложение (демо-режим)
Никакой установки не нужно — просто откройте файл в браузере:

```
index.html
```

В демо-режиме код подтверждения Telegram **показывается на экране** (так как бот
не подключён), поэтому весь сценарий регистрации можно пройти без сервера.

> Совет: для корректной работы как PWA лучше открыть через локальный сервер,
> например `npx serve .` или `python3 -m http.server`.

**Демо-вход администратора:** телефон `+998 90 123 45 67`, пароль `admin`
(или кнопка «Войти как админ клуба (демо)» на экране регистрации клуба).

### Вариант 2. С Telegram-ботом (реальные коды)

1. Создайте бота у **@BotFather** и получите токен.
2. Настройте backend:
   ```bash
   cd server
   cp .env.example .env
   # откройте .env и вставьте BOT_TOKEN=...   (и BOT_USERNAME=...)
   node index.js
   ```
   Сервер поднимется на `http://localhost:8787`, **раздаёт само приложение** и
   предоставляет API. В логах появится `[bot] connected as @<username>`.
3. Включите backend во фронтенде — в начале `index.html`:
   ```html
   <script>
     window.MVP_CONFIG = {
       useBackend: true,          // тот же origin, что и сервер
       botUsername: 'ВашБот'      // @username вашего бота
     };
   </script>
   ```
   (Если фронтенд на другом домене — укажите `apiBase: 'http://ваш-сервер:8787'`.)
4. Откройте `http://localhost:8787`. Теперь при регистрации:
   нажатие «Получить код» → «Открыть Telegram-бот» → **Start** → боту приходит
   4-значный код → вводите его в приложении.

#### Как это работает
```
Приложение ──request-code(phone)──▶ Backend  (создаёт сессию, отдаёт t.me/<bot>?start=<token>)
Пользователь открывает ссылку, жмёт START в боте
Бот (long polling) ──sendMessage(код)──▶ Telegram пользователя
Приложение ──verify-code(token, код)──▶ Backend  ─▶ { ok: true } ─▶ вход выполнен
```

## 🗂 Структура проекта

```
mvpgaming/
├── index.html              # точка входа (подключает модули)
├── manifest.webmanifest    # PWA-манифест
├── css/
│   └── styles.css          # вся стилизация (тёмная тема, красный акцент)
├── js/
│   ├── i18n.js             # переводы RU / UZ / EN
│   ├── icons.js            # встроенные SVG-иконки
│   ├── art.js              # генератор обложек (SVG, работает офлайн)
│   ├── data.js             # стартовые данные: клубы, комнаты, промокоды, игры
│   ├── store.js            # состояние + сохранение в localStorage
│   ├── telegram.js         # запрос/проверка кода (backend или демо)
│   ├── app.js              # роутер + экраны пользователя
│   └── admin.js            # экраны и логика админ-панели
└── server/
    ├── index.js            # Telegram-бот + API (без зависимостей)
    ├── package.json
    └── .env.example        # шаблон конфигурации (скопировать в .env)
```

Данные приложения хранятся в `localStorage` браузера: правки клуба, комнат,
бронирования, избранное и язык сохраняются между сессиями. Чтобы сбросить —
очистите хранилище сайта в браузере.

## 🔐 Безопасность

- **Токен бота хранится только в `server/.env`** (он в `.gitignore`) и никогда
  не попадает во фронтенд или в репозиторий.
- Коды одноразовые и живут ограниченное время (`CODE_TTL_MIN`, по умолчанию 10 мин).
- Если вы где-то публиковали токен бота — **отзовите/перевыпустите его** через
  @BotFather → `/mybots` → *API Token* → *Revoke*.

---

## 🌐 Языки и переводы

Все строки интерфейса вынесены в `js/i18n.js` (ключ → `ru` / `uz` / `en`).
Полнота переводов и отсутствие «сырых» ключей проверяются автоматическим
смоук-тестом. Переключение языка — в «Профиль → Настройки».

## 📦 Деплой

Фронтенд — статика, разворачивается где угодно (GitHub Pages, Netlify, Vercel,
nginx). Для реальных Telegram-кодов разместите `server/index.js` на хосте с
доступом к `api.telegram.org` (VPS, Railway, Render и т.п.) и укажите его в
`MVP_CONFIG`.
