# Cardify — генератор инфографики товаров с ИИ

Веб-сервис для создания продающих карточек (инфографики) для маркетплейсов
(Wildberries, Ozon). Пользователь загружает фото товара, ИИ определяет категорию
(аксессуар, бытовая техника, игрушка, электроника, бьюти) и подбирает подходящий
шаблон дизайна. Готовую карточку можно отредактировать и скачать в PNG.

## Возможности

- **Лендинг** с примерами 4 стилей дизайна (вдохновлены топовыми карточками WB).
- **Регистрация / вход** (демо-аутентификация на `localStorage`).
- **Редактор карточки**: загрузка фото, выбор шаблона, редактирование текста,
  преимуществ, характеристик, экспорт PNG.
- **ИИ-классификация товара** по фото (OpenAI Vision, с fallback-заглушкой).
- **Тарифы / подписки** (Free / Pro, демо-оплата).
- **Личный кабинет** с сохранёнными карточками.
- **Техподдержка** со ссылками на соцсети и формой обращения.

## Структура

```
frontend/   # Vite + React + TypeScript + Tailwind (UI, редактор, шаблоны)
backend/    # FastAPI (классификация фото + генерация фона через OpenAI)
```

## Запуск

### Backend
```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
cp .env.example .env   # при наличии впишите OPENAI_API_KEY
uvicorn app.main:app --reload --port 8000
```
Без ключа бэкенд работает в демо-режиме (заглушка-классификатор).

### Frontend
```bash
cd frontend
npm install
cp .env.example .env   # VITE_API_BASE=http://localhost:8000
npm run dev
```

## ИИ

Распознавание товара и генерация фона используют OpenAI API. Задайте
`OPENAI_API_KEY` в `backend/.env`. Модели настраиваются через
`OPENAI_VISION_MODEL` (по умолчанию `gpt-4o-mini`) и `OPENAI_IMAGE_MODEL`
(по умолчанию `gpt-image-1`). Если ключа нет — классификация работает в
демо-режиме, а генерация фона возвращает сообщение о недоступности.
