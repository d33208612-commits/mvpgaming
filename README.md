# Kartix AI — AI-инфографика для маркетплейсов

Премиальный SaaS-сервис, который превращает обычное фото товара в профессиональную
продающую карточку для **Uzum Market**, **Wildberries** и **Ozon**. Пользователь
загружает изображение — искусственный интеллект анализирует товар, пишет тексты и
собирает готовую инфографику из нескольких слайдов.

> 🇷🇺 Русский · 🇺🇿 O‘zbekcha · 🇬🇧 English — интерфейс и генерация на трёх языках.

---

## ✨ Возможности

- **Drag & drop загрузка** фото товара (на главной и в студии).
- **AI-анализ изображения** — извлечение реальной палитры цветов из фото, определение
  категории, материалов, особенностей и преимуществ.
- **AI-копирайтер** — автоматически создаёт название, продающее описание, преимущества
  и SEO-текст, если у пользователя нет своего описания.
- **Генерация 5 слайдов карточки**:
  1. Главный продающий слайд
  2. Преимущества товара
  3. Характеристики
  4. Сравнение «мы / другие»
  5. Бонусный блок (доставка, гарантия, возврат, подарок) + CTA
- **Свой промпт** на русском, узбекском и английском.
- **Мультиязычная генерация** карточек (RU / UZ / EN) — переключение в один клик.
- **Шаблоны под маркетплейсы** с правильными размерами:
  - Uzum — 1080×1440
  - Wildberries — 900×1200
  - Ozon — 1080×1440
  - + универсальные форматы (1:1, 9:16) в редакторе.
- **Редактор карточек**: тексты, акцентный цвет и палитра, стиль дизайна (6 пресетов),
  шрифт, добавление/удаление блоков, переключение маркетплейса и размера — всё с живым
  предпросмотром.
- **Личный кабинет**: история созданных карточек, сохранённые проекты, генерация новых
  вариантов, скачивание и статистика использования.
- **Экспорт** в **PNG** (каждый слайд, HD для платных тарифов) и **PDF** (все слайды).
- **Система подписок**: Free / Pro / Business с лимитами генераций и водяным знаком на
  Free, помесячной и годовой оплатой.
- **Премиальный UI**: тёмная и светлая темы, стеклянные элементы (glassmorphism),
  mesh-градиенты, плавные анимации и 3D-акценты.

## 🎨 Стили дизайна слайдов

`3D Премиум` · `Минимал` · `Яркий` · `Техно` · `Эко` · `Пастель` — каждый стиль
по-разному собирает фон, палитру и композицию вокруг цвета товара.

## 🧠 Как устроен AI

Сервис работает в **двух режимах** и сам выбирает доступный:

### 1. Настоящий AI — Claude API (рекомендуется)

Если запущен бэкенд (`server.js`) с ключом `ANTHROPIC_API_KEY`, генерация идёт через
**Claude** (`@anthropic-ai/sdk`):

- **Vision-анализ.** Claude **смотрит на загруженное фото**, определяет товар,
  категорию, материалы, особенности и преимущества.
- **Структурированный вывод.** Через **tool use** (`generate_card`) Claude возвращает
  готовый JSON ровно той формы, которую рисует фронтенд — название, продающий
  заголовок, описание, бейдж, скидку, чипы, преимущества, характеристики, сравнение,
  бонусы, SEO-текст, размерный ряд и цену — на выбранном языке (RU / UZ / EN).
- **Промпт-кэширование** системного промпта и **выбор модели** (по умолчанию
  `claude-opus-4-8`, можно переключить через `KARTIX_MODEL`).
- Ключ хранится **только на сервере** — в браузер он не попадает. В студии загорается
  бейдж «⚡ Claude AI».

Палитра и сам кадр товара по-прежнему извлекаются на клиенте (через `<canvas>`), а
тексты и анализ приходят от Claude — composition собирается фронтенд-рендерером.

### 2. Локальный демо-режим (fallback)

Без сервера/ключа (или при сетевой ошибке) всё работает **в браузере**: палитра
извлекается из фото через `<canvas>`, категория — по эвристике, а тексты собираются из
многоязычных банков фраз (`js/data.js`). Сайт остаётся полностью рабочим офлайн и с
`file://`. Переключение между режимами — автоматическое и незаметное для пользователя.

> Интеграция изолирована: на сервере — `AI.analyze`/`AI.writeCopy` → один вызов
> `messages.create` с картинкой и инструментом; на клиенте — `AI.generateRemote` +
> `mergeRemoteCard`. Формат карточки в обоих режимах одинаковый.

## 🚀 Запуск

### С настоящим AI (Claude API)

```bash
npm install                     # ставит express + @anthropic-ai/sdk
cp .env.example .env            # впишите ANTHROPIC_API_KEY в .env
npm start                       # → http://localhost:8787
```

Сервер раздаёт фронтенд и проксирует генерацию к Claude. Модель по умолчанию —
`claude-opus-4-8`; для меньшей стоимости можно поставить `KARTIX_MODEL=claude-sonnet-4-6`
или `claude-haiku-4-5` в `.env`.

### Без ключа (демо-режим)

```bash
# просто откройте index.html в браузере, либо:
python3 -m http.server 8000     # → http://localhost:8000
```

Без `ANTHROPIC_API_KEY` сайт работает на локальном генераторе. Экспорт в PNG/PDF
использует `html2canvas` и `jsPDF`, встроенные локально (`js/vendor/`), поэтому работает
офлайн и прямо с `file://`.

## 🧪 Тесты

```bash
npm install
npm test     # jsdom-сценарий (локальный режим) + тесты бэкенда (запрос/парсинг/маршруты)
```

Дополнительно: `node test/live.test.mjs` — проверка live-пути (карточка от Claude →
маппинг → рендер); `npm run shots` — скриншоты в реальном браузере (нужен Chromium).

## 📁 Структура

```
server.js          — Node/Express бэкенд: раздача статики + /api/generate (Claude)
.env.example       — шаблон конфигурации (ANTHROPIC_API_KEY, KARTIX_MODEL, PORT)
index.html         — разметка: лендинг, студия, кабинет, модальные окна
css/styles.css     — дизайн-система, темы, glassmorphism, рендер слайдов
js/i18n.js         — переводы RU / UZ / EN и движок локализации
js/data.js         — маркетплейсы, категории, стили, банки текстов, тарифы
js/app.js          — состояние, AI (live + локальный), рендер слайдов, студия,
                     редактор, экспорт, кабинет, авторизация, подписки
js/vendor/         — html2canvas и jsPDF (для экспорта PNG/PDF)
test/harness.mjs   — интеграционный тест (локальный режим, jsdom)
test/live.test.mjs — тест live-пути Claude (jsdom + стаб бэкенда)
test/server.test.cjs — тесты бэкенда (запрос/схема/парсинг/маршруты)
rentcar.html       — отдельный проект из репозитория (не связан с Kartix)
```

## 🛠️ Технологии

**Фронтенд:** ванильный HTML + CSS + JavaScript (без фреймворков и сборщиков) ·
`html2canvas` · `jsPDF` · `localStorage`.
**Бэкенд:** Node.js + Express · `@anthropic-ai/sdk` (Claude — vision + tool use +
prompt caching).
